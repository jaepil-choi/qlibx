# Agent Instructions

`AGENTS.md` is the canonical repository instruction file.

Read and follow, in order:

1. the root `AGENTS.md`
2. the nearest nested `AGENTS.md`
3. `.agent/project.yaml`
4. any skill selected for the current task

Do not maintain a duplicate policy in this file. When guidance needs to change, update the
canonical file or the narrowly scoped skill that owns the workflow.
