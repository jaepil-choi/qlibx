result.

## One process deviation, stated

The eight issues landed as one branch with one commit rather than one branch each. Four files —
`SKILL.md`, `public.py`, `cli/run.py`, and the refusal baseline — are shared across issues, and the
baseline regenerates from whatever the working tree holds, so per-issue commits could not each be
green. The commit message says so; this repeats it here because the previous campaign's lesson was
that an unstated deviation is the problem, not the deviation.
