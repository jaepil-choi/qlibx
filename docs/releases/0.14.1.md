## The run takes what the verification loaded and read (record `242`)

A `FrozenRun` is a record value and carries no live object, so after verifying a run `vqapr run`
imported the strategy, the venue and every rule again and scanned the execution table again for
its horizon on the first accepted intent. `verify_run`'s verdict now carries `RunResources` -- the
instances the verification loaded and the horizon it cut -- and `run` takes them: `vqapr run`,
`--jobs` workers and any caller using `RunVerdict.require_ready()` import nothing twice and scan
the horizon once. A caller holding only a `FrozenRun` (`public.preflight_run` then `public.run`)
still gets a run that loads for itself. Resources frozen for another run are refused.
