vqapr 0.5.0 척추 디버거 — 실제 데이터가 지나간 길을 한 프레임씩

이 페이지의 모든 프레임은 상상이 아니라 트레이스입니다. KRX 실제 일봉(data/DW, 10종목 × 735세션)으로 sample panel을 만들고 vqapr register → check → run(전략) → list → show → rm → run(datamodel) → run mixed → run --jobs 2 → list strategies --run을 명령마다 별도 프로세스에서 sys.setprofile로 추적했습니다. 프레임의 file:line은 트레이스가 기록한 함수 정의 줄이고, #idx는 그 명령 안에서 몇 번째 호출인지, ms는 프로파일러가 켜진 채 잰 시간입니다. 스니펫은 요약이 아니라 그 시점의 소스 줄입니다. 0.4.1판과 같은 여정을 같은 데이터로 다시 밟았고, 0.5.0(한 모양 캠페인 Step 0~7, 기록 151~162)이 옮긴 파일·이름·문이 어디서 보이는지를 프레임마다 적었습니다.
