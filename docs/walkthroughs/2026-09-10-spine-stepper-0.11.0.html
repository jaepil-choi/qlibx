vqapr 0.11.0 척추 디버거 — 루프 하나, 시계 둘, 행은 열로

이 페이지의 모든 프레임은 상상이 아니라 트레이스입니다. vqapr new sample이 만든 sample door(10종목, 2022-01-03 ~ 2024-12-30)에 15세션짜리 전략 run(sample-run-short, Compliance no-short 하나)과 datamodel run(sample-features-run)을 선언하고, vqapr register → check → run(전략) → run(datamodel) → list runs → show run → show strategy → list strategies → register(거절)를 명령마다 별도 프로세스에서 sys.setprofile로 추적했습니다(experiments/exp_230_the_spine_trace/). 프레임의 file:line은 트레이스가 기록한 함수 정의 줄, #idx는 그 명령 안에서 몇 번째 호출인지, ms는 프로파일러가 켜진 채 잰 시간입니다. 스니펫은 요약이 아니라 그 시점의 소스 줄입니다. 0.6.0판과 같은 여정을 밟되, 0.11.0이 바꾼 것 — 루프 하나(RunLoop · Part · MarketClock, 기록 227), 시장 시계 한 점은 다섯 줄의 fold(기록 226), 행은 열로 흐른다(RecordChunk, 기록 221), 집행표는 미리 읽는다(기록 222), run 전체의 sequence(기록 225), 역할은 Call 하나를 받는다(observe(call), 기록 229) — 가 어느 프레임에서 보이는지를 적었습니다.
