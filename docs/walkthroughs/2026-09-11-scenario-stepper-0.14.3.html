vqapr 0.14.3 시나리오 디버거 — 사용자가 하는 일 여섯 가지 + 배치 하나, 프레임워크 안에서 한 프레임씩

이 페이지는 vqapr이 실제로 무엇을 하는지를, 실제로 돌린 기록으로 보여 줍니다. vqapr new sample이 만든 작은 프로젝트(종목 10개, 2022-01-03 ~ 2024-12-30, 거래일 735일)에서 사용자가 할 법한 일곱 가지를 차례로 합니다: ① 데이터를 등록하고, ② 등록이 거절되는 두 경우를 보고, ③ 종목별 지표(5일 모멘텀)를 만드는 DataModel을 돌리고, ④ 그 지표로 상위 3개는 사고 하위 3개는 파는 factor 전략을 돌리고, ⑤ 진입가를 기억해 3% 빠지면 파는 stop-loss 전략을 돌리고, ⑥ ④가 남긴 비중을 읽어 enhanced index를 만들고, ⑦ ④와 ⑤를 동시에(--jobs 2) 돌립니다. 읽는 법: 프레임마다 위쪽 문장은 지금 일어나는 일을 보통 말로 적은 것이고, 아래 접힌 곳에 함수 이름과 호출 번호(#idx)와 ms가 있습니다. 위쪽만 읽어도 흐름이 이어지도록 썼습니다. 0.14.3에서 새로 달라진 자리(콜백이 읽은 것을 한 번만 만들고, 집행표는 run 기간만큼만 읽고, 심장 박동은 초당 한 번)는 그 프레임에 [0.14.3]으로 표시했습니다. 모든 번호와 ms는 sys.setprofile이 실제로 기록한 값이고, 스니펫은 그 시점의 소스 줄입니다 — 상상한 것은 없습니다(experiments/exp_249_the_scenario_trace_0_14_3/).

먼저 알아 두면 편한 낱말 열한 개

선언 (declaration) — 당신이 쓰는 YAML. "이 parquet은 가격이다, 이 파일은 내 전략이다, 이 run은 이렇게 돌려라." 레시피에 해당한다.
등록부 (workspace) — .vqapr/workspace.yaml. register가 쓰고 모든 명령이 맨 처음 펼쳐 읽는 장부. 코드에선 Workspace.
문 (door) — 물리 파일을 실제로 열어 재는 한 곳(data/validation.py): 컬럼 · 키 · 기간 · 값 · 집행 가격 · digest. 등록될 때 한 번 재고, 그 뒤엔 내용이 아니라 digest(지문)만 대조한다.
digest (지문) — 파일 바이트의 sha256. 파일이 한 바이트라도 바뀌면 지문이 달라져 읽는 쪽이 알아챈다.
얼리기 (freeze) — 등록부의 이름들을 실제 값(코드 지문, parquet 경로와 digest, 결정 시각 목록, 초기 계좌)으로 풀어 밀봉한 것 = FrozenRun. 도시락에 해당한다: run 도중 레시피(등록부)가 바뀌어도 도시락은 그대로다.
판정 (judgments) · 문 하나 (verify_run) — "이 run을 돌려도 되나"에 답하는 예/아니오 여럿. check는 전부 모아 보여 주고 run은 첫 거절에서 멈춘다. 둘 다 verify_run 한 함수를 지나며 같은 사실(RunFacts)을 한 번만 읽는다.
두 시계 — 전략 시계: 결정하는 시각(매일 08:00이나 09:00, 16:00). 시장 시계: 집행표에 가격이 있는 시각(매일 15:30). 아침에 결정하고 오후에 체결·평가한다. 트레이스의 시각은 UTC라 06:30 = 15:30 KST.
창 (window) · panel — 전략이 읽는 데이터의 사각형: 시각 × 종목. panel은 그 행렬(float64) 한 벌이고, matrix()는 복사 없이 그 일부를 보는 view다. run의 기간 + lookback만큼만 읽는다.
memory — 전략의 self.memory. 엄격한 JSON. 매 결정 전에 복원되고 뒤에 저장된다. 이것만 믿을 수 있다 — 다른 self 속성은 기록이 재현하지 못한다.
의도서 (intent) — 전략이 돌려준 목표 비중에 프레임워크가 도장을 찍은 것. 체결 시각이 올 때까지 하나만 기다린다(pending). Hold면 없다.
봉투 (envelope) — 모든 명령이 stdout에 내는 JSON 한 덩어리. 성공이든 거절이든 모양이 같다: ok · stage · failures[code · status · requirement · observed · fix].
